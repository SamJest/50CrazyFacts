Baboons Can Use Rocks and Sticks to Access Food

Primitive tool use shows cleverness.

Baboons have been observed breaking nuts with stones or using sticks to dig for tubers. Tool use is learned socially and sometimes innovated individually. These behaviors allow access to food otherwise unavailable, increasing caloric intake. Tool use demonstrates problem-solving, planning, and fine motor control. Observation of these behaviors provides insights into cognitive evolution.
