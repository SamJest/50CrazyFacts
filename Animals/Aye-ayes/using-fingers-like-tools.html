Using Fingers Like Tools

After locating insects, aye-ayes use their long finger to extract them.

The finger hooks and pulls prey with remarkable precision.

Why This Matters

No other mammal uses an internal “tool” in this way.

This behavior highlights a sophisticated form of foraging.

Did You Know?

Did you know this finger movement is so precise it can extract prey from holes smaller than a pencil?
