Aye-Ayes Can Remember Foraging Sites Over Long Distances

Memory is key for nocturnal survival.

Aye-ayes remember which trees have been productive for larvae and can revisit them days later. Spatial memory helps them reduce wasted energy while foraging and maintain territories. They also recall which branches or holes were already harvested. This ability demonstrates cognitive mapping skills unusual for solitary primates. Efficient memory use ensures they maximize caloric intake while avoiding unnecessary risk.
