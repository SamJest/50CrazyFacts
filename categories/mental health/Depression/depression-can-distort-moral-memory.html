Depression Can Distort Moral Memory

Past errors dominate. Success fades. Balance is lost.

Depression biases moral memory recall. Negative actions are remembered vividly. Positive behavior is forgotten. This reinforces guilt. Memory balance returns with treatment.

Why This Matters

It matters because distorted memory fuels shame. Self-image collapses.

Correcting recall bias supports recovery. Memory retraining helps.

Did You Know?

Did you know memory bias modification is an active research area in depression treatment.

[Psychological Medicine, Cambridge University Press]
