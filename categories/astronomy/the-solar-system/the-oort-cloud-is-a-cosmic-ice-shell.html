The Oort Cloud Is a Cosmic Ice Shell

Edge of the solar system.

The Oort Cloud is a hypothesized spherical shell of icy objects surrounding the Sun at distances up to 100,000 AU. It’s thought to be the source of long-period comets. No spacecraft has visited it, but indirect evidence supports its existence.

Why This Matters

This matters because it represents the solar system’s outermost frontier.

It also shows how far the Sun’s gravitational influence extends.

Did You Know?

The Oort Cloud may contain trillions of icy bodies, forming a vast comet reservoir.
