Dark Flow Was First Detected Using X-Ray Telescopes

Observing invisible motion through light. X-rays revealed cosmic drift.

A team led by Alexander Kashlinsky in 2008 first reported Dark Flow using NASA’s Chandra X-ray Observatory. They observed clusters via their hot gas emitting X-rays. By studying the kinematic Sunyaev-Zel’dovich effect, they measured subtle shifts in the CMB caused by cluster motion. This method allowed astronomers to detect a large-scale, coherent motion. Multiple follow-ups confirmed the effect. It marked a turning point in observational cosmology. X-rays are key because optical light is insufficient to measure such tiny motions.

Why This Matters

It matters because detecting Dark Flow requires innovative observational techniques.

X-ray astronomy opens new windows to measure cosmic velocities.

Did You Know?

It demonstrates how advanced instruments can uncover universe-scale anomalies.
