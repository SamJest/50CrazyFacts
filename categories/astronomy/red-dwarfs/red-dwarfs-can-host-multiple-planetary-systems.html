Red Dwarfs Can Host Multiple Planetary Systems

Crowded stars.

Some red dwarfs have multiple planets orbiting very closely, sometimes with several Earth-sized worlds in the habitable zone.

Why This Matters

This increases the odds of finding potentially habitable worlds.

It also provides insights into planet formation around small stars.

Did You Know?

One red dwarf can host a solar system of several tightly packed planets.
