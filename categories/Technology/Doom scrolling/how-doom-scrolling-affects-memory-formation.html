How Doom Scrolling Affects Memory Formation

Scrolling leaves fewer memories.

Rapid content prevents encoding into long-term memory. The brain discards most of what it sees. This creates a sense of emptiness afterward. Time feels wasted because little is remembered. Memory thrives on structure, not chaos. Doom scrolling provides none.

Why This Matters

It matters because memory shapes identity.

It also affects learning retention.

Did You Know?

Fast content reduces memory retention significantly.
